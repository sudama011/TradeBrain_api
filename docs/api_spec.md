# 📖 TradeBrain API Reference

**Base URL:** `/api/v1`
**Protocol:** `HTTPS` (Production) / `HTTP` (Development)
**Authentication:** Bearer Token (`Authorization: Bearer <token>`)

## 📨 Response Format (Standard Envelope)

To ensure consistency and support pagination, all API responses follow a strict **Envelope Pattern**. Clients should always access the payload via the `data` key.

### Success Response Structure

All successful (2xx) responses return JSON in this format:

```json
{
  "data": { ... },         // The actual resource (Object or Array)
  "meta": {                // Optional metadata (pagination, timestamps)
    "timestamp": "2024-01-03T10:30:00Z"
  }
}

```

### Pagination Example (`GET /signals`)

When returning a list, `data` contains the array, and `meta` contains pagination details.

```json
{
  "data": [
    { "id": "1", "ticker": "TATASTEEL" },
    { "id": "2", "ticker": "RELIANCE" }
  ],
  "meta": {
    "total": 150,
    "page": 1,
    "page_size": 20,
    "total_pages": 8,
    "timestamp": "2024-01-03T10:30:00Z"
  }
}

```

### Error Response Structure

Error responses (4xx, 5xx) follow a consistent format:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid email format",
    "details": { "email": "value is not a valid email address" }
  }
}

```

## 🔐 1. Authentication & User Management

Handles user lifecycle, sessions, and device registration for push notifications.

### Auth Endpoints

#### **POST** `/auth/register`

Create a new account.

**Request:**

```json
{
  "email": "user@example.com",
  "password": "SecurePassword123!",
  "full_name": "John Doe"
}

```

**Response:** `201 Created`

```json
{
  "data": {
    "id": "uuid",
    "email": "user@example.com",
    "full_name": "John Doe",
    "role": "USER",
    "created_at": "2024-01-03T10:30:00Z"
  }
}

```

#### **POST** `/auth/login`

Authenticate using email/password. Returns `access_token` (short-lived) and `refresh_token` (long-lived).

**Request:**

```json
{
  "email": "user@example.com",
  "password": "SecurePassword123!"
}

```

**Response:** `200 OK`

```json
{
  "data": {
    "access_token": "eyJhbGc...",
    "refresh_token": "eyJhbGc...",
    "token_type": "bearer",
    "expires_in": 900
  }
}

```

#### **POST** `/auth/refresh`

Exchange a valid `refresh_token` for a new `access_token`.

**Request:**

```json
{
  "refresh_token": "eyJhbGc..."
}

```

**Response:** `200 OK`

```json
{
  "data": {
    "access_token": "eyJhbGc...",
    "token_type": "bearer",
    "expires_in": 900
  }
}

```

#### **POST** `/auth/logout`

Invalidate the current session (deletes the refresh token from DB).

**Response:** `200 OK`

### User Endpoints

#### **GET** `/users/me`

Retrieve the profile of the currently authenticated user.

**Response:** `200 OK`

```json
{
  "data": {
    "id": "uuid",
    "email": "user@example.com",
    "full_name": "John Doe",
    "role": "USER",
    "created_at": "2024-01-03T10:30:00Z"
  }
}

```

#### **POST** `/users/devices`

Register a device's Push Token to enable mobile notifications.

**Request:**

```json
{
  "device_token": "fcm_or_apns_token_here",
  "platform": "IOS",
  "device_name": "John's iPhone 14"
}

```

**Response:** `201 Created`

```json
{
  "data": {
    "id": 1,
    "device_token": "fcm_or_apns_token_here",
    "platform": "IOS",
    "is_active": true,
    "registered_at": "2024-01-03T10:30:00Z"
  }
}

```

#### **DELETE** `/users/devices/{device_id}`

Unregister a specific device (typically on logout).

**Response:** `204 No Content`

## 📈 2. Signals (The Feed)

The core engine output. Provides intelligent trading setups generated by the AI Analysts.

### Signal Endpoints

#### **GET** `/signals`

Fetches paginated trading signals with advanced filters.

**Query Parameters:**

* `page` (int, default: 1)
* `page_size` (int, default: 20)
* `ticker` (string, optional)
* `action` (string, optional) - `BUY`, `SELL`
* `status` (string, optional) - `ACTIVE`, `HIT_TARGET`, etc.
* `setup_type` (string, optional) - `BREAKOUT`, `PULLBACK`
* `min_confidence` (int, optional) - 0-100
* `sort_by` (string, default: "created_at")

**Response:** `200 OK`

```json
{
  "data": [
    {
      "id": "uuid",
      "ticker": "TATASTEEL",
      "action": "BUY",
      "status": "ACTIVE",
      "setup_type": "BREAKOUT",
      "confidence": 85,
      "time_horizon": "3-5 Days",
      "entry_price": 150.50,
      "target_price": 165.00,
      "stop_loss": 145.00,
      "risk_reward_ratio": 2.0,
      "reasoning": "Strong technical breakout with positive news catalyst",
      "source_urls": ["https://example.com/news1"],
      "created_at": "2024-01-03T10:30:00Z"
    }
  ],
  "meta": {
    "total": 150,
    "page": 1,
    "page_size": 20,
    "total_pages": 8
  }
}

```

#### **GET** `/signals/{signal_id}`

Detailed view of a signal, including full AI analysis and risk flags.

**Response:** `200 OK`

```json
{
  "data": {
    "id": "uuid",
    "ticker": "TATASTEEL",
    "action": "BUY",
    "status": "ACTIVE",
    "setup_type": "BREAKOUT",
    "confidence": 85,
    "entry_price": 150.50,
    "target_price": 165.00,
    "stop_loss": 145.00,
    "reasoning": "Strong technical breakout...",
    "warning_flags": ["earnings_tomorrow"],
    "source_urls": ["https://example.com/news1"],
    "created_at": "2024-01-03T10:30:00Z"
  }
}

```

#### **POST** `/signals/{signal_id}/favorite`

Save a signal to the user's "Favorites" list.

**Response:** `201 Created`

#### **DELETE** `/signals/{signal_id}/favorite`

Remove a signal from favorites.

**Response:** `204 No Content`

#### **GET** `/signals/favorites`

Retrieve only the signals the user has saved.

**Response:** `200 OK` (Same format as GET `/signals`)

### Admin Signal Operations (Optimization Layer)

#### **GET** `/signals/pending-review`

Get signals flagged by the **Validation Engine** that require human approval (e.g., "Earnings Tomorrow").

**Response:** `200 OK`

```json
{
  "data": [
    {
      "id": "uuid",
      "ticker": "ZOMATO",
      "action": "BUY",
      "status": "PENDING_REVIEW",
      "confidence": 80,
      "warning_flags": ["earnings_tomorrow", "high_volatility"],
      "requires_admin_approval": true,
      "created_at": "2024-01-03T10:30:00Z"
    }
  ]
}

```

#### **POST** `/signals/{signal_id}/approve`

Approve a signal pending review. Sets status to `ACTIVE`.

**Request:**

```json
{ "notes": "Approved despite earnings risk." }

```

**Response:** `200 OK`

#### **POST** `/signals/{signal_id}/reject`

Reject a signal pending review. Sets status to `REJECTED`.

**Response:** `200 OK`

## 💰 3. Portfolio & Paper Trading

Links the UserTrade model to the Signal model to track user performance.

### Trade Endpoints

#### **POST** `/trades`

"Take" a trade. Can be linked to a Signal or standalone.

**Request:**

```json
{
  "signal_id": "uuid",
  "ticker": "TATASTEEL",
  "side": "BUY", 
  "entry_price": 150.50,
  "quantity": 10
}

```

**Response:** `201 Created`

```json
{
  "data": {
    "id": "uuid",
    "signal_id": "uuid",
    "ticker": "TATASTEEL",
    "side": "BUY",
    "entry_price": 150.50,
    "quantity": 10,
    "status": "OPEN",
    "created_at": "2024-01-03T10:30:00Z"
  }
}

```

#### **GET** `/trades`

Fetch the user's trade history.

**Query Parameters:**

* `status` (string, optional) - `OPEN`, `CLOSED`
* `side` (string, optional) - `BUY`, `SELL`
* `ticker` (string, optional)

**Response:** `200 OK`

```json
{
  "data": [
    {
      "id": "uuid",
      "ticker": "TATASTEEL",
      "side": "BUY",
      "entry_price": 150.50,
      "exit_price": 162.00,
      "quantity": 10,
      "status": "CLOSED",
      "pnl": 1150.00,
      "pnl_percentage": 7.65,
      "created_at": "2024-01-03T10:30:00Z"
    }
  ]
}

```

#### **PATCH** `/trades/{trade_id}`

Close an active trade. Backend auto-calculates P&L.

**Request:**

```json
{
  "exit_price": 162.00
}

```

**Response:** `200 OK`

#### **GET** `/trades/stats`

Returns aggregate performance data (Win Rate, Total PnL, Profit Factor).

**Response:** `200 OK`

```json
{
  "data": {
    "total_trades": 25,
    "win_rate": 0.75,
    "total_pnl": 5000.00,
    "profit_factor": 2.25
  }
}

```
