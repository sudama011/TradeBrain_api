# 📖 TradeBrain API Reference

**Base URL:** `/api/v1`

**Protocol:** `HTTPS` (Production) / `HTTP` (Development)

**Authentication:** Bearer Token (`Authorization: Bearer <token>`)

**Response Format:** All responses are JSON with consistent structure:
```json
{
  "data": { /* response payload */ },
  "meta": { "timestamp": "2024-01-03T10:30:00Z" }
}
```

---

## 🔐 1. Authentication & User Management

Handles user lifecycle, sessions, and device registration for push notifications.

### Auth Endpoints

#### **POST** `/auth/register`
Create a new account. Sets the default role to USER unless specified.

**Request:**
```json
{
  "email": "user@example.com",
  "password": "SecurePassword123!",
  "full_name": "John Doe"
}
```

**Response:** `201 Created`
```json
{
  "data": {
    "id": "uuid",
    "email": "user@example.com",
    "full_name": "John Doe",
    "role": "USER",
    "created_at": "2024-01-03T10:30:00Z"
  }
}
```

#### **POST** `/auth/login`
Authenticate using email/password. Returns access_token and refresh_token.

**Request:**
```json
{
  "email": "user@example.com",
  "password": "SecurePassword123!"
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "access_token": "eyJhbGc...",
    "refresh_token": "eyJhbGc...",
    "token_type": "bearer",
    "expires_in": 3600
  }
}
```

#### **POST** `/auth/refresh`
Exchange a refresh_token for a new access_token to maintain session persistence.

**Request:**
```json
{
  "refresh_token": "eyJhbGc..."
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "access_token": "eyJhbGc...",
    "token_type": "bearer",
    "expires_in": 3600
  }
}
```

#### **POST** `/auth/logout`
Invalidate the current session and blacklist the token.

**Response:** `200 OK`
```json
{
  "data": { "message": "Successfully logged out" }
}
```

### User Endpoints

#### **GET** `/users/me`
Retrieve the profile of the currently authenticated user.

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "email": "user@example.com",
    "full_name": "John Doe",
    "role": "USER",
    "created_at": "2024-01-03T10:30:00Z",
    "updated_at": "2024-01-03T10:30:00Z"
  }
}
```

#### **PATCH** `/users/me`
Update personal details like name or preferences.

**Request:**
```json
{
  "full_name": "Jane Doe",
  "preferences": {
    "notifications_enabled": true,
    "email_alerts": true
  }
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "email": "user@example.com",
    "full_name": "Jane Doe",
    "updated_at": "2024-01-03T10:35:00Z"
  }
}
```

#### **POST** `/users/devices`
Register a device's FCM/APNS token to enable mobile push notifications.

**Request:**
```json
{
  "device_token": "fcm_token_here",
  "device_type": "ios",
  "device_name": "iPhone 14"
}
```

**Response:** `201 Created`
```json
{
  "data": {
    "id": "uuid",
    "device_token": "fcm_token_here",
    "device_type": "ios",
    "device_name": "iPhone 14",
    "registered_at": "2024-01-03T10:30:00Z"
  }
}
```

#### **DELETE** `/users/devices/{device_id}`
Unregister a specific device token (typically on logout).

**Response:** `204 No Content`

## 📈 2. Signals (The Feed)

The core engine output. Provides intelligent trading setups generated by the AI Analysts.

### Signal Endpoints

#### **GET** `/signals`
Fetches paginated trading signals with advanced filters.

**Query Parameters:**
- `page` (int, default: 1) - Page number
- `page_size` (int, default: 20) - Items per page
- `ticker` (string, optional) - Filter by ticker symbol
- `action` (string, optional) - Filter by action (BUY/SELL/HOLD)
- `status` (string, optional) - Filter by status (ACTIVE/PENDING/HIT_TARGET/HIT_STOP_LOSS)
- `min_confidence` (int, optional) - Minimum confidence score (0-100)
- `sort_by` (string, default: "created_at") - Sort field (created_at, confidence, risk_reward)
- `sort_order` (string, default: "desc") - Sort order (asc/desc)

**Response:** `200 OK`
```json
{
  "data": [
    {
      "id": "uuid",
      "ticker": "TATASTEEL",
      "action": "BUY",
      "status": "ACTIVE",
      "confidence": 85,
      "entry_price": 150.50,
      "target_price": 165.00,
      "stop_loss": 145.00,
      "risk_reward_ratio": 2.0,
      "reasoning": "Strong technical breakout with positive news catalyst",
      "source_urls": ["https://example.com/news1"],
      "created_at": "2024-01-03T10:30:00Z",
      "updated_at": "2024-01-03T10:30:00Z"
    }
  ],
  "meta": {
    "total": 150,
    "page": 1,
    "page_size": 20,
    "total_pages": 8
  }
}
```

#### **GET** `/signals/{signal_id}`
Detailed view of a signal, including AI reasoning and source URLs.

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "ticker": "TATASTEEL",
    "action": "BUY",
    "status": "ACTIVE",
    "confidence": 85,
    "entry_price": 150.50,
    "target_price": 165.00,
    "stop_loss": 145.00,
    "risk_reward_ratio": 2.0,
    "reasoning": "Strong technical breakout with positive news catalyst",
    "technical_analysis": "RSI > 70, MACD bullish crossover",
    "fundamental_analysis": "Q3 earnings beat expectations",
    "catalyst": "New contract announcement",
    "source_urls": ["https://example.com/news1", "https://example.com/news2"],
    "created_at": "2024-01-03T10:30:00Z",
    "updated_at": "2024-01-03T10:30:00Z"
  }
}
```

#### **POST** `/signals/{signal_id}/favorite`
Save a signal to the user's "Favorites" list.

**Response:** `201 Created`
```json
{
  "data": {
    "signal_id": "uuid",
    "favorited_at": "2024-01-03T10:35:00Z"
  }
}
```

#### **DELETE** `/signals/{signal_id}/favorite`
Remove a signal from favorites.

**Response:** `204 No Content`

#### **GET** `/signals/favorites`
Retrieve only the signals the user has saved.

**Query Parameters:** Same as GET `/signals`

**Response:** `200 OK` (Same format as GET `/signals`)

#### **PATCH** `/signals/{signal_id}` (Admin Only)
Manually override a signal's status (e.g., MANUAL_CLOSED).

**Request:**
```json
{
  "status": "MANUAL_CLOSED",
  "notes": "Closed due to market conditions"
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "status": "MANUAL_CLOSED",
    "updated_at": "2024-01-03T10:40:00Z"
  }
}
```

#### **GET** `/signals/pending-review`
Get all signals pending admin approval (Admin only).

**Query Parameters:**
- `page` (int, default: 1)
- `page_size` (int, default: 20)

**Response:** `200 OK`
```json
{
  "data": [
    {
      "id": "uuid",
      "ticker": "TATASTEEL",
      "action": "BUY",
      "status": "PENDING_REVIEW",
      "confidence": 85,
      "entry_price": 150.50,
      "target_price": 165.00,
      "stop_loss": 145.00,
      "warning_flags": ["earnings_tomorrow", "high_volatility"],
      "requires_admin_approval": true,
      "created_at": "2024-01-03T10:30:00Z"
    }
  ],
  "meta": {
    "total": 5,
    "page": 1,
    "page_size": 20
  }
}
```

#### **POST** `/signals/{signal_id}/approve` (Admin Only)
Approve a signal that is pending review.

**Request:**
```json
{
  "notes": "Approved despite earnings. Strong technical setup."
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "status": "ACTIVE",
    "approved_by_admin": "admin_uuid",
    "approved_at": "2024-01-03T10:45:00Z",
    "admin_notes": "Approved despite earnings. Strong technical setup."
  }
}
```

#### **POST** `/signals/{signal_id}/reject` (Admin Only)
Reject a signal that is pending review.

**Request:**
```json
{
  "notes": "Too risky with earnings tomorrow"
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "status": "CANCELLED",
    "admin_notes": "Too risky with earnings tomorrow"
  }
}
```

## 💰 3. Portfolio & Paper Trading

Links the UserTrade model to the Signal model to track user performance.

### Trade Endpoints

#### **POST** `/trades`
"Take" a trade based on an existing signal.

**Request:**
```json
{
  "signal_id": "uuid",
  "entry_price": 150.50,
  "quantity": 10
}
```

**Response:** `201 Created`
```json
{
  "data": {
    "id": "uuid",
    "signal_id": "uuid",
    "ticker": "TATASTEEL",
    "entry_price": 150.50,
    "quantity": 10,
    "status": "OPEN",
    "entry_date": "2024-01-03T10:30:00Z",
    "target_price": 165.00,
    "stop_loss": 145.00
  }
}
```

#### **GET** `/trades`
Fetch the user's trade history.

**Query Parameters:**
- `page` (int, default: 1)
- `page_size` (int, default: 20)
- `status` (string, optional) - Filter by status (OPEN/CLOSED/CANCELLED)
- `ticker` (string, optional) - Filter by ticker

**Response:** `200 OK`
```json
{
  "data": [
    {
      "id": "uuid",
      "signal_id": "uuid",
      "ticker": "TATASTEEL",
      "entry_price": 150.50,
      "exit_price": 162.00,
      "quantity": 10,
      "status": "CLOSED",
      "pnl": 1150.00,
      "pnl_percentage": 7.65,
      "entry_date": "2024-01-03T10:30:00Z",
      "exit_date": "2024-01-04T14:00:00Z"
    }
  ],
  "meta": {
    "total": 25,
    "page": 1,
    "page_size": 20
  }
}
```

#### **PATCH** `/trades/{trade_id}`
Close an active trade. The backend automatically calculates P&L based on the exit_price.

**Request:**
```json
{
  "exit_price": 162.00
}
```

**Response:** `200 OK`
```json
{
  "data": {
    "id": "uuid",
    "status": "CLOSED",
    "exit_price": 162.00,
    "pnl": 1150.00,
    "pnl_percentage": 7.65,
    "exit_date": "2024-01-04T14:00:00Z"
  }
}
```

#### **GET** `/trades/stats`
Returns aggregate performance data.

**Response:** `200 OK`
```json
{
  "data": {
    "total_trades": 25,
    "open_positions": 3,
    "closed_trades": 22,
    "total_pnl": 5000.00,
    "total_pnl_percentage": 8.5,

    "avg_win": 450.00,
    "avg_loss": -200.00,
    "largest_win": 1500.00,
```

**Query Parameters:**

```json
  "ticker": "TATASTEEL",
  "priority": 1,
```

Control the background scanning and auditing jobs.

### Scheduler Endpoints

#### **GET** `/scanner/scheduler/status`
Get the current status of the scheduler.

**Response:** `200 OK`
```json
{
  "data": {
    "is_running": true,
    "jobs": [
      {
        "id": "market_scanner",
        "name": "Market Scanner Job",
        "next_run_time": "2024-01-03T15:00:00Z",

      {
        "id": "signal_auditor",

        "next_run_time": "2024-01-03T10:35:00Z",
        "trigger": "cron[*/30 9-16 * * 1-5]"
      }
    ]
  }
}
```

#### **POST** `/scanner/scheduler/start`
Start the scheduler (Admin only).

**Response:** `200 OK`
```json
{
  "data": {
    "message": "Scheduler started successfully",
    "is_running": true
  }
}
```

#### **POST** `/scanner/scheduler/stop`
Stop the scheduler (Admin only).

**Response:** `200 OK`
```json
{
  "data": {
    "message": "Scheduler stopped successfully",
    "is_running": false
```

#### **POST** `/scanner/scheduler/trigger`

## 🛑 Common Status Codes

| Code | Meaning | Description |
| ---- | ------- | ----------- |
| 200  | OK      | Request successful. |
| 201  | Created | Resource successfully created. |
| 204  | No Content | Request successful, no content to return. |
| 400  | Bad Request | Request contained invalid data. |
| 401  | Unauthorized | Authentication failed or token expired. |
| 403  | Forbidden | Insufficient permissions (e.g., not admin). |
| 404  | Not Found | Resource not found. |
| 422  | Validation Error | Input data did not pass schema validation. |
| 429  | Too Many Requests | Rate limit exceeded. |
| 500  | Server Error | Internal system failure. |
| 503  | Service Unavailable | Service temporarily unavailable. |

---

## 📋 Signal Status Values

| Status | Description |
|--------|-------------|
| `PENDING` | Signal created, awaiting confirmation |
| `ACTIVE` | Signal is active and being monitored |
| `HIT_TARGET` | Signal reached target price |
| `HIT_STOP_LOSS` | Signal hit stop loss |
| `EXPIRED` | Signal expired (no action within timeframe) |
| `MANUAL_CLOSED` | Manually closed by admin |
| `CANCELLED` | Cancelled due to market conditions |

---

## 📋 Trade Status Values

| Status | Description |
|--------|-------------|
| `OPEN` | Trade is currently open |
| `CLOSED` | Trade has been closed |
| `CANCELLED` | Trade was cancelled |

## 💡 Example Workflows

### 1. User Registration & Login
```bash
# Register
POST /auth/register
{
  "email": "user@example.com",
  "password": "SecurePassword123!",
  "full_name": "John Doe"
}

# Login
POST /auth/login
{
  "email": "user@example.com",
  "password": "SecurePassword123!"
}

# Use access_token in Authorization header
Authorization: Bearer <access_token>
```

### 2. Add Ticker & Monitor Signals
```bash
# Add ticker to watchlist
POST /watchlist
{
  "ticker": "TATASTEEL",
  "priority": 1
}

# Get signals for ticker
GET /signals?ticker=TATASTEEL&min_confidence=75

# Favorite a signal
POST /signals/{signal_id}/favorite
```

```bash
# Take a trade
POST /trades
{
  "signal_id": "uuid",
  "entry_price": 150.50,
  "quantity": 10
}

# Get trade stats
GET /trades/stats

# Close a trade
PATCH /trades/{trade_id}
{
  "exit_price": 162.00
}
```

### 4. Admin: Trigger Manual Scan
```bash
# Check scheduler status
GET /scanner/scheduler/status

# Trigger manual scan
POST /scanner/scheduler/trigger

  "job_id": "market_scanner"
```
